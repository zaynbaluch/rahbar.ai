# Bayaz AI Current Scope

The current implementation scope is limited to the Android/Flutter teacher application and the tooling directly required to build its bundled curriculum content.

Items concerning a backend, public website, administration portal, licensing, payments, cloud analytics, district dashboards, or other external systems are research-only unless explicit implementation approval is provided.

Research-only work may include:

- requirements analysis;
- flowcharts and wireframes;
- architecture recommendations;
- risks and edge cases;
- data-model proposals;
- pseudocode;
- testing recommendations.

Research-only work must not add:

- runnable external services;
- websites;
- database migrations;
- deployment configurations;
- cloud dependencies;
- new app runtime dependencies;
- background services;
- production credentials.

Every backlog item must be labelled as one of:

1. Implement in app
2. Simplified app prototype
3. Research only
4. Deferred

When a requirement is uncertain or explicitly described as requiring research, default to research only. Do not convert research recommendations into implementation without approval.

The MVP should prefer the smallest implementation that demonstrates the teacher workflow on a real Android device. New architecture must be justified by a current app requirement rather than a possible future requirement.
