# Current App Documentation

This directory documents only the active Flutter app, curriculum build tooling, and validation requirements.

- `APP_ARCHITECTURE.md` - current local-first runtime boundaries.
- `USER_FLOWS.md` - active teacher workflows and click-depth targets.
- `decisions/` - architecture decision records for the app and content pipeline.
- `content/` - content quality gates and the current pack audit.
- `omr/` - OMR validation requirements.
- `setup/` - pinned toolchain and release checklist.
- `branding/` - current visual identity.
- `pedagogy-research.md` - pedagogy notes supporting content design.

External systems belong in `../research/` and must not be treated as implemented components.
